# 🛍️ Landing Page de Promociones - Tienda por Departamentos SEMO

¡Bienvenido al repositorio oficial de la **Landing Page de Promociones y Eventos Exclusivos para SEMO**! Este proyecto consiste en un sitio web moderno, elegante y totalmente responsivo diseñado para resaltar las ofertas especiales de la tienda, eventos de temporada y la captación de nuevos clientes a través de un formulario de suscripción.

## 📋 Características Principales
- **Visualización Clara de Promociones:** Secciones destacadas para promociones relámpago, colecciones de temporada y eventos exclusivos.
- **Diseño Atractivo y Elegante:** Paleta de colores sofisticada con una tipografía refinada que refleja la identidad de tienda por departamentos premium.
- **Formulario de Suscripción:** Sección para capturar correos electrónicos de clientes e inscribirlos al club de promociones.
- **Navegación Multi-página:** Incluye **3 páginas enlazadas** para ofrecer una experiencia completa al usuario.
- **Diseño Responsivo Sin Media Queries:** Adaptabilidad completa para computadoras y dispositivos móviles basada en técnicas modernas de CSS layout (Flexbox/Grid fluido, unidades relativas y funciones de ajuste como `clamp()`, `min()`, `max()`, `auto-fit` / `auto-fill`).
- **Uso de Contenido Multimedia:** Integración de imágenes optimizadas y elementos audiovisuales para maximizar el engagement.
- **Semántica HTML5:** Estructura desarrollada respetando las mejores prácticas de desarrollo web, accesibilidad y SEO.

---

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica completa (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Estilos avanzados, variables CSS (Custom Properties), tipografía web, paleta de colores coherente y maquetación fluida.
- **Google Fonts:** Integración de al menos 2 familias tipográficas para jerarquía visual (encabezados y cuerpo de texto).
